# /name Command

Quick name the current conversation with smart title suggestions.

When you say just "name", I will:
1. Analyze the current conversation content
2. Generate 4 intelligent, differentiated title suggestions
3. Let you choose from the options
4. Apply the rename immediately

You can also:
- Say "name terminal [title]" to rename your terminal tab
- Say "name this [specific title]" to use a custom title directly

The skill will automatically detect what you want to name based on context.

Note: Conversations are now automatically given a working name based on your first message when they start. You can always rename them later with this command.
