# Final Digest Report Format

Template for the compiled report combining all video summaries, personality agent assessment, and cross-cutting analysis.

---

```markdown
# YouTube Video Digest, [DATE]

## Overview

**Videos processed:** [N] of [Total]
**Date:** [YYYY-MM-DD]
**Failed:** [List any that failed, or "None"]

**Note:** [Any observations, e.g. "Videos 1 and 5 were the same talk"]

---

## Individual Video Summaries

### Video 1: [Title]
**URL:** [url]
**Relevance: [HIGH / MEDIUM / LOW]**

[Full agent summary including all subsections:
Key Takeaways, Surprising Info, Practical Implications,
Notable Quotes, Critical Assessment]

---

### Video 2: [Title]
[Continue for each video]

---

## Personal Relevance Assessment

[Full output from the personality agent, including:
- Per-video relevance scores and reasoning
- Connections to existing thinking/insights
- Watch recommendations (full/selective/skip)]

---

## Cross-Video Themes

[Only include if 2+ videos processed]

### Theme: [Name]
- **Videos:** [Which ones]
- **Pattern:** [What connects them]
- **Why it matters for you:** [Specific connection to interests/work]

---

## Actionable Items

- [ ] [Action 1, from whichever section it originated]
- [ ] [Action 2]
- [ ] [Continue]

---

## Gaps and Missing Perspectives

- [Content gaps across all videos]
- [Failed video fetches]
- [Perspectives the user would care about that were absent]

---

*Generated by youtube-digesting-videos skill on [DATE]*
```

## Notes

- The overview should flag duplicates or related videos
- Individual summaries are included in full, not abbreviated
- The personality agent assessment comes AFTER individual summaries so the reader gets the raw content first, then the personalized lens
- Actionable items are consolidated from both the video agents and the personality agent
- Keep the report factual. No performative enthusiasm about the digest itself.
